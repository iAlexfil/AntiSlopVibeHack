# AntiSlop MVP

Веб-инструмент для проверки изображений на признаки AI-генерации. Базовый анализ выполняется локально; по желанию изображение параллельно проверяется через настроенные внешние API.

Изображение можно выбрать, перетащить в окно или вставить напрямую из буфера через `Ctrl+V` / `Cmd+V`.

## Интерфейс

Первый экран — тёмный лендинг с анимированным фоном и кнопкой «Проверить изображение». Кнопка сразу открывает выбор файла; затем интерфейс переводит к превью и запуску анализа. Доступны также drag-and-drop и вставка из буфера. Во время анализа видны сканирующая линия и текстовый статус. Ошибки показываются рядом с формой, а при сбое проверку можно повторить.

Результат содержит крупный итоговый процент, понятное объяснение, число ответивших моделей и согласованность источников. Ниже — пять направлений анализа; технический отчёт с метаданными и диагностическими картами раскрывается по желанию. Если нет ни модельных ответов, ни положительных признаков происхождения, показано «Недостаточно данных».

Интерфейс адаптирован для телефона, планшета и компьютера, поддерживает клавиатуру и настройку уменьшения движения. Canvas-фон ограничен 30 кадрами/с и приостанавливается вне экрана. Шрифты Manrope и Unbounded хранятся локально с лицензиями OFL; сторонние библиотеки для анимации не нужны.

## Что проверяется

- EXIF, XMP, IPTC и текстовые метаданные;
- PNG text chunks, JPEG comments и читаемые строки контейнера;
- C2PA / Content Credentials / JUMBF-сигнатуры;
- маркеры Midjourney, DALL·E, Stable Diffusion, Firefly, Imagen/Gemini, Ideogram, Leonardo, Runway, NovelAI, Flux и других сервисов;
- эвристика контрастного бейджа в углах для последующей ручной проверки.
- независимые ML-детекторы Hive, Sightengine, AI or Not и WasItAI.
- локальный Frontier ViT и явная сводная вероятность AI-генерации;
- опциональный смысловой анализ сцены через OpenAI Vision (анатомия, физика, текст и противоречия сюжета);
- опциональная проверка SynthID и C2PA через OpenAI Content Provenance API;
- криптографическая проверка C2PA через официальный CAI SDK;
- ELA-карта, шумовой остаток, частотный спектр и карта повторяющихся паттернов;
- SHA-256, perceptual hash и difference hash для поиска копий и вариантов;
- проверка логики EXIF-полей.

Инструмент не заявляет, что определяет любую AI-картинку. Метаданные можно удалить. Проверка SynthID через OpenAI распознаёт только поддерживаемые OpenAI сигналы и не покрывает все изображения Google или других генераторов. Отсутствие метки не подтверждает подлинность.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Открыть `http://127.0.0.1:8000`.

## Подключение API

Скопируйте `.env.example` в `.env` и заполните ключи тех сервисов, которые хотите использовать:

```bash
cp .env.example .env
```

После изменения `.env` перезапустите сервер.

| Сервис | Переменные |
| --- | --- |
| Hive | `HIVE_API_KEY` |
| Sightengine | `SIGHTENGINE_API_USER`, `SIGHTENGINE_API_SECRET` |
| AI or Not | `AIORNOT_API_KEY` |
| WasItAI | `WASITAI_API_KEY` |
| OpenAI Vision | `OPENAI_API_KEY` (модель можно сменить через `OPENAI_VISION_MODEL`) |
| OpenAI SynthID / C2PA | `OPENAI_API_KEY` (тот же ключ, что для Vision) |

Ключи читаются только сервером и не возвращаются в браузер. Запросы выполняются параллельно с таймаутом 25 секунд. Переключатель «Дополнительная проверка» над кнопкой анализа позволяет провести только локальную проверку. Рядом явно указано, будет ли изображение передано внешним сервисам.

Проверка OpenAI SynthID / C2PA отправляет исходный файл без ресайза или перекодирования в `POST /v1/content_provenance_checks`. Поддерживаются PNG, JPEG и WebP; другие форматы пропускаются. Как и остальные внешние проверки, она выполняется только при `remote=true`. Для локального режима выберите анализ без внешних API.

В полном отчёте сохраняются отдельные результаты SynthID и C2PA, а также доступные сведения о модели, времени генерации, издателе и состоянии валидации. API возвращает признаки происхождения, а не вероятность AI. Обнаруженный SynthID или обнаруженный C2PA со статусом `trusted` / `valid` добавляют один provenance-сигнал `0.99` в общее среднее. Этот сигнал общий с локальной проверкой C2PA, поэтому одна и та же информация не учитывается дважды. `not_detected` не снижает итоговую оценку. Остальные вероятностные результаты и metadata-сигнал `0.95` объединяются по прежним правилам.

Доступность API зависит от организации OpenAI. Ответы 400 (неподдерживаемый или заблокированный файл), 404 (API недоступен организации), 429 (лимит запросов), таймауты и другие ошибки показываются в отчёте и не прерывают анализ. Автоматических повторов нет. Контракт: [руководство OpenAI](https://developers.openai.com/api/docs/guides/content-provenance), [справочник API](https://developers.openai.com/api/reference/resources/content_provenance_checks/methods/create).

Illuminarty не публикует общий контракт API и остаётся недоступным. Покрытие других генераторов через SynthID требует отдельного поддерживаемого API.

## Ограничение памяти

Численные forensic-проверки всегда работают с уменьшенной копией изображения: максимум 1024 px по длинной стороне, а FFT — максимум 512 px. Изображения больше 40 мегапикселей отклоняются до полной декомпрессии. Локальная ONNX-модель запускается на каждый запрос в отдельном процессе с одним CPU-потоком, лимитом адресного пространства 768 МБ и таймаутом 28 секунд; после ответа процесс завершается. На тестовом изображении её пиковый RSS составил около 214 МБ.

На проверенном macOS arm64 установка лимита памяти завершается ошибкой `current limit exceeds maximum limit`, поэтому локальная ML-модель недоступна. Метаданные, криминалистика и подключённые API продолжают работать; ошибка модели видна в подробном отчёте. Для macOS требуется отдельная реализация контроля памяти, существующую защиту отключать нельзя.

Процент в интерфейсе - скрининговая сводка доступных моделей и признаков происхождения, а не доказательство. Если нет ни вероятностных ответов, ни положительных признаков AI-происхождения, показывается "Недостаточно данных", а не вводящие в заблуждение 0%.
